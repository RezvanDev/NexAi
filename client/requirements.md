framer-motion | Essential for the pulsing voice visualizer and smooth page transitions

## Notes
- Using browser's built-in `window.SpeechRecognition` (and `webkitSpeechRecognition`) for STT.
- Using `window.speechSynthesis` for TTS.
- Fallback text input provided if browser doesn't support Speech API.
- "Phone call" aesthetic with glassmorphism and deep colors.
